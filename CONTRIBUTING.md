# Contributing

This repo is pre-port — the real toolchain (Biome, tests, lint/build
commands) lands with [#1](https://github.com/alrayyes/washy-washy-web/issues/1),
the extraction of `apps/web` from `washy-washy`. This file will fill in
with real, pasteable commands once that lands.

Until then, what already holds:

- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
- Work lands through a pull request — no direct pushes to `main`.
- One logical change per commit and per PR.
