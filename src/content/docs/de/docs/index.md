Washy washy macht aus einer Wäschetabelle etwas, das du tatsächlich vor der
Maschine stehend lesen kannst: eine handyfreundliche Seite, filterbar nach
Ansicht und nach Stapel. Ein separates
[CLI](https://github.com/alrayyes/washy-washy-cli) liest dieselbe Wäsche-
und Maschinenbeschreibung und rendert sie stattdessen als PDF — diese Seite
behandelt nur die Web-App; das CLI hat sein eigenes README für Installation
und Nutzung.

Fang mit dem an, was zu deinem Vorhaben passt:

- **[Die Wäsche- und Maschinendateien](/de/docs/chart-and-machine/)** — jedes
  Feld deiner Wäschetabelle, wie die Maschinendatei deine Waschmaschine und
  dein Bügeleisen beschreibt, und wie die Mischregeln entscheiden, was sich
  eine Trommel teilen darf.
- **[Die Web-App nutzen](/de/docs/web-app/)** — die Filter auf der Startseite,
  was zwischen Besuchen erhalten bleibt, und wie ein hier hochgeladenes
  Konfigurationsfile sich zum mitgelieferten Beispiel verhält.
- **[Eine Konfiguration mit einem KI-Chat-Tool erstellen](/de/docs/ai-prompt/)**
  — füge einen copy-paste-fertigen Prompt und Fotos deiner Waschmaschine und
  deines Bügeleisens ein und erhalte eine Konfigurationsdatei zurück, die
  diese App laden kann.
