Washy washy 把一份洗衣图表变成一个你站在洗衣机前就能真正看懂的东西：一个适合手机浏览的页面，可以按范围和按衣物堆筛选。另有一个独立的 [CLI](https://github.com/alrayyes/washy-washy-cli) 会读取同一份图表和机器描述，并将其渲染为 PDF——本站只介绍网页应用；CLI 的安装和运行方法见它自己的 README。

从最符合你需求的部分开始：

- **[图表与机器文件](/zh/docs/chart-and-machine/)** ——图表中的每个字段、机器文件如何描述你的洗衣机和熨斗，以及混洗规则如何决定哪些衣物可以共用一个滚筒。
- **[使用网页应用](/zh/docs/web-app/)** ——首页上的筛选器、哪些内容会在多次访问之间保留，以及在这里上传配置与内置示例的关系。
- **[用 AI 聊天工具生成配置](/zh/docs/ai-prompt/)** ——粘贴一段可直接复制的提示词和你洗衣机、熨斗的照片，换回一份这个应用可以加载的配置文件。
