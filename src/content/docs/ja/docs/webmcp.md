[WebMCP](https://webmachinelearning.github.io/webmcp/)は実験的なブラウザAPIです — W3C Web Machine Learning Community Groupの草案で、まだどのブラウザもデフォルトでは実装していません — ページがツールを宣言し、AIエージェントがあなた自身のブラウザタブの中で、あなた自身のデータに対して直接呼び出せるようにするものです。これは[AIチャットツールでconfigを生成する](/ja/docs/ai-prompt/)の自動化版です。ダウンロードしたconfigを貼り付けて結果を貼り戻す代わりに、WebMCPを理解するエージェントがブラウザ内で既に有効なconfigを直接読み書きします。検証方法はどちらの経路でも同じです。

そうしたブラウザや拡張機能を持たない人にとっては、アプリの動作は何も変わりません。`document.modelContext`は単に存在せず、このページの5つのツールが登録されることもありません。どちらの場合でも、configがどこかに送信されることはありません。ツール呼び出しは、ここの他のどのページも既に使っている、`localStorage`に保存された同じconfigを読み書きするだけです。

## 5つのツール

| ツール                 | 内容                                                                                                                                                                          |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `washy_get_config`     | 有効なチャートとマシンを読み取ります — 自分のもの、または同梱のサンプルです。                                                                                                 |
| `washy_validate_chart` | 何も保存せずに、チャートの行を有効なマシンに照らして検証します。                                                                                                              |
| `washy_set_chart`      | 検証したうえで、有効なチャートを置き換えます — [`/config`](https://washy-washy.ryankes.eu/config/) で保存するのと同じです。                                                   |
| `washy_set_machine`    | 有効な洗濯機とアイロンを置き換え、現在のチャートをそれらに照らして再検証します — [`/config/machine`](https://washy-washy.ryankes.eu/config/machine/) で保存するのと同じです。 |
| `washy_export_pdf`     | 有効なチャートをPDF（スマホ用またはプリント用レイアウト）としてレンダリングし、ダウンロードではなくデータとして返します。                                                     |

これらはすべて、ページ上のエディタが使うのと同じ
[`@washy-washy/core`](https://github.com/alrayyes/washy-washy-core)
の検証を通ります — エージェントが書いた行があなたのマシンに合わない場合、チャートエディタが表示するのと同じ行・列のエラーで失敗します。黙って推測することはありません。

## 保存された変更はページを再読み込みします

`washy_set_chart`と`washy_set_machine`は、保存が完了すると同時にページを再読み込みします。ヘッダーからconfigをアップロードしたときに既に起きるのと同じ動作です。開いているエディタとツール呼び出しの間にライブ同期はないため、再読み込みによって内容が追いつきます。

## 自分で試す

WebMCP対応のブラウザ拡張機能をインストールするか、このサイトでブラウザの開発者コンソールを開き、`await document.modelContext.getTools()`を呼び出してください — ネイティブサポートかポリフィルが存在すれば、どれかを呼び出す前に、5つのツールすべてを名前と説明付きで一覧表示します。
