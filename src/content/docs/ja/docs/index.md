---

Washy washy は洗濯表示を、洗濯機の前に立ったまま実際に読めるものに変えます。スマホ向けのページで、生地の種類と量ごとに絞り込みができます。別の[CLI](https://github.com/alrayyes/washy-washy-cli)が同じチャートと洗濯機の記述を読み込み、PDFとして出力します — このサイトが扱うのはウェブアプリのみです。CLIのインストールと実行方法は、CLI自身のREADMEにあります。

やりたいことに合わせて、以下から選んでください。

- **[チャートと洗濯機のファイル](/ja/docs/chart-and-machine/)** — チャートの各項目、洗濯機ファイルであなたの洗濯機とアイロンをどう記述するか、そして混ぜ合わせルールがどのように同じドラムで洗えるかを決めるか。
- **[ウェブアプリを使う](/ja/docs/web-app/)** — トップページのフィルター、訪問間で保持される内容、そしてここでconfigをアップロードすることが同梱のサンプルとどう関係するか。
- **[AIチャットツールでconfigを生成する](/ja/docs/ai-prompt/)** — コピペ用のプロンプトと、洗濯機・アイロンの写真を渡せば、このアプリが読み込めるconfigファイルが返ってきます。
