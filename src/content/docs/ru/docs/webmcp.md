[WebMCP](https://webmachinelearning.github.io/webmcp/) — это
экспериментальный API браузера, черновик Web Machine Learning Community
Group консорциума W3C, который пока не реализован по умолчанию ни в одном
браузере, — он позволяет странице объявлять инструменты, которые
ИИ-агент может вызывать напрямую, в вашей собственной вкладке браузера,
над вашими собственными данными. Это автоматизированная версия
[создания конфигурации с помощью инструмента ИИ-чата](/ru/docs/ai-prompt/):
вместо того чтобы вставлять скачанную конфигурацию, а затем вставлять
результат обратно, агент, понимающий WebMCP, напрямую читает и
записывает конфигурацию, уже активную в вашем браузере, проверенную
точно так же, как и в обоих случаях.

Для тех, у кого нет такого браузера или расширения, здесь ничего не
меняется: `document.modelContext` просто не будет существовать, и пять
инструментов этой страницы никогда не регистрируются. Никакая
конфигурация никуда не отправляется в любом случае: вызов инструмента
читает и записывает ту же хранящуюся в `localStorage` конфигурацию,
которую уже использует любая другая страница здесь.

## Пять инструментов

| Инструмент             | Делает                                                                                                                                                                                           |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `washy_get_config`     | Читает активные таблицу и машину — вашу собственную или встроенный пример.                                                                                                                       |
| `washy_validate_chart` | Проверяет строки таблицы по активной машине, ничего не сохраняя.                                                                                                                                 |
| `washy_set_chart`      | Заменяет активную таблицу, предварительно проверив её — то же самое, что нажать «Сохранить» на [`/config`](https://washy-washy.ryankes.eu/config/).                                              |
| `washy_set_machine`    | Заменяет активные стиральную машину и утюг, заново проверяя текущую таблицу по ним — то же самое, что нажать «Сохранить» на [`/config/machine`](https://washy-washy.ryankes.eu/config/machine/). |
| `washy_export_pdf`     | Рендерит активную таблицу в PDF (макет для телефона или для печати), возвращая её как данные, а не скачивая.                                                                                     |

Каждый из них проходит ту же проверку
[`@washy-washy/core`](https://github.com/alrayyes/washy-washy-core),
что и редакторы на странице — строка, которую написал агент и которая не
подходит вашей машине, завершится той же ошибкой с указанием строки и
столбца, что показал бы редактор таблицы, а не молчаливой догадкой.

## Сохранённые изменения перезагружают страницу

`washy_set_chart` и `washy_set_machine` перезагружают страницу сразу
после сохранения — точно так же, как уже делает загрузка конфигурации
через шапку сайта. Живой синхронизации между открытым редактором и
вызовом инструмента нет, поэтому перезагрузка — это то, как страница
догоняет изменения.

## Попробуйте сами

Установите расширение браузера с поддержкой WebMCP или откройте консоль
разработчика вашего браузера на этом сайте и вызовите `await
document.modelContext.getTools()` — как только появится нативная
поддержка или полифилл, это выведет список всех пяти инструментов с
именем и описанием, прежде чем вы вызовете хоть один из них.
