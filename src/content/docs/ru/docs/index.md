Washy washy превращает таблицу стирки в то, что можно реально прочитать,
стоя перед машиной: страницу, удобную для телефона, с фильтрами по срезу и
по стопке белья. Отдельный
[CLI](https://github.com/alrayyes/washy-washy-cli) читает то же описание
таблицы и машины и вместо этого рендерит его в PDF — этот сайт описывает
только веб-приложение; у CLI есть собственный README по установке и
запуску.

Начните с того, что подходит вашей задаче:

- **[Файлы таблицы и машины](/ru/docs/chart-and-machine/)** — каждое поле
  вашей таблицы стирки, как файл машины описывает вашу стиральную машину и
  утюг, и как правила смешивания решают, что может делить один барабан.
- **[Использование веб-приложения](/ru/docs/web-app/)** — фильтры на
  главной странице, что сохраняется между визитами, и как загруженный сюда
  конфиг соотносится со встроенным примером.
- **[Создание конфигурации с помощью ИИ-чата](/ru/docs/ai-prompt/)** —
  вставьте готовый к копированию промпт и фотографии вашей стиральной
  машины и утюга и получите обратно файл конфигурации, который это
  приложение сможет загрузить.
