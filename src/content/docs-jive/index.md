Washy washy takes that ol' laundry chart an' makes it somethin' you can actually dig standin' right there in front o' the iron horse: a jive page that's slick on your jive-stick, sortable by cut an' by pile. There's a separate [CLI](https://github.com/alrayyes/washy-washy-cli), Jack, that reads the same chart an' machine rap sheet an' cooks it up into a PDF instead — this here joint's just coverin' the web app; the CLI's got its own README for gettin' it up an' movin'.

Kick off with whichever jive's cookin' with what you're tryin' to do:

- **[The chart an' machine jive](/jive/docs/chart-and-machine/)** — every field on your chart, how the machine jive lays out your washer an' iron, an' how the mixin' rules figure what's cool to share a drum.
- **[Workin' the web app](/jive/docs/web-app/)** — the sift-outs on the front page, what sticks around after you split, an' how dumpin' a config here jives with the bundled example.
- **[Cookin' up a config with an AI rap tool](/jive/docs/ai-prompt/)** — paste a copy-an'-paste-ready rap an' snapshots o' your washer an' iron, an' get back a config file this cat can chew on.
